Το Raspberry Pi Pico W έχει έναν ενσωματωμένο LED. Παρακάτω, θα δούμε πώς μπορούμε να ανάψουμε και να σβήσουμε αυτό το LED (blink), χρησιμοποιώντας τις μεθόδους on() και off(). Επίσης, θα χρησιμοποιήσουμε την μέθοδο *sleep()* της βιβλιοθήκης *time*, για να δημιουργήσουμε τα χρονικά διαστήματα κατά οποία θα είναι αναμμένο και σβηστό το led. 

```
# Εισάγουμε τις μεθόδους για τον χειρισμό των ακίδων (pin) του Raspberry Pico
from machine import Pin
# Εισάγουμε την βιβλιοθήκη time για να χρησιμοποιήσουμε την μέθοδο sleep
import time

# Δημιουργούμε ένα αντικείμενο (led) από την κλάση Pin, ορίζοντας ότι θα χρησιμοποιήσουμε το Pin 25 για έξοδο
led = Pin("LED", machine.Pin.OUT)

for i in range(10):
    led.on() # Ανάβουμε το led
    time.sleep(1) # Αναγκάζουμε το rpi να περιμένει (να μην κάνει καμία άλλη ενέργεια) για 1 δευτερόλεπτο
    led.off() # Σβήνουμε το led
    time.sleep(1)
```
*Εκτός από τις μεθόδους on() και off(), έχουμε στην διάθεσή μας και την μέθοδο toggle() με την οποία μπορούμε να αλλάζουμε την κατάσταση που βρίσκεται το led. Δηλαδή, όποτε είναι αναμμένο το led, θα το σβήνει και το αντίθετο*.

## Ασκήσεις

Τι αλλαγές πρέπει να κάνουμε στον κώδικα για να:
1. Ανάβει και να σβήνει το led για πάντα;
2. Ανάβει και να σβήνει πολύ γρήγορα το led; Τι παρατηρούμε αν μειώσουμε πάρα πολύ το διάστημα που είναι αναμμένο/σβηστό το led;
3. Χρησιμοποιείται η μέθοδος toggle() για την διαδικασία *blink*.

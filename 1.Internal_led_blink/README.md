Το Raspberry Pi Pico W έχει έναν ενσωματωμένο LED. Παρακάτω, θα δούμε πώς μπορούμε να ανάψουμε και να σβήσουμε αυτό το LED, χρησιμοποιώντας τις μεθόδους on() και off(). Επίσης, θα χρησιμοποιήσουμε την μέθοδο sleep της βιβλιοθήκης time, για να δημιουργήσουμε τα χρονικά διαστήματα κατά οποία θα είναι αναμμένο και σβηστό το led. 

```
# Εισάγουμε τις μεθόδους για τον χειρισμό των ακίδων (pin) του Raspberry Pico
from machine import Pin
# Εισάγουμε την βιβλιοθήκη time για να χρησιμοποιήσουμε την μέθοδο sleep
import time

# Δημιουργούμε ένα αντικείμενο (led) από την κλάση Pin, ορίζοντας ότι θα χρησιμοποιήσουμε το Pin 25 για έξοδο
led = Pin("LED", machine.Pin.OUT)

for i in range(10):
    led.on() # Ανάβουμε το led
    time.sleep(1) # Αναγκάζουμε το rpi να περιμένει (να μην κάνει καμία άλλη ενέργεια) για 1 δευτερόλεπτο
    led.off() # Σβήνουμε το led
    time.sleep(1)
```
*Η toggle() είναι μια μέθοδος με την οποία μπορούμε να αλλάζουμε την κατάσταση που βρίσκεται το led. Δηλαδή, όποτε είναι αναμμένο, το led, θα το σβήσει και το αντίθετο*
## Ασκήσεις

1. Τι αλλαγές πρέπει να κάνουμε στον κώδικα για να ανάβει και να σβήνει το led για πάντα;
2. Αν θέλουμε να ανάβει και να σβήνει πολύ γρήγορα, τι αλλαγές πρέπει να κάνουμε; Τι παρατηρούμε αν μειώσουμε πάρα πολύ τον διάστημα που είναι αναμμένο και σβηστό το led;
3. Τροποποιήστε το πρόγραμμα έτσι ώστε να χρησιμοποιεί την μέθοδο toggle() για την διαδικασία *blink*.

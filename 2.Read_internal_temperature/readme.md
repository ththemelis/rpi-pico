# Μέτρηση θερμοκρασίας με τον εσωτερικό αισθητήρα

Το Raspberry Pi Pico έχει έναν ενσωματωμένο αισθητήρα θερμοκρασίας, ο οποίος είναι συνδεδεμένος στην πόρτα ADC4. Παρακάτω, θα δούμε πώς μπορούμε να πάρουμε μετρήσεις από αυτόν τον αισθητήρα.

## Ο αισθητήρας θερμοκρασίας του Rpi Pico W

Ο αισθητήρας θερμοκρασίας του Rpi Pico W δεν είναι υψηλής ακρίβειας και χρησιμοποιείται μόνο για να πάρουμε μια γενική εικόνα για την θερμοκρασία. Όταν η θερμοκρασία είναι 27 βαθμούς Κελσίου, έχει τάση 0.706V και για κάθε ένα βαθμό, η τάση μεταβάλλεται κατά 1.721mV.

Για την μετατροπή της τάση σε βαθμούς Κελσίου, πρέπει να χρησιμοποιήσουμε τον παρακάτω τύπο:

```T = 27 - (ADC_voltage - 0.706)/0.001721```

Με το παρακάτω τμήμα κώδικα, έχουμε την δυνατότητα να διαβάσουμε την θερμοκρασία.

```
# Εισαγωγή της κλάσης ADC από την βιβλιοθήκη machine
from machine import ADC

# Δημιουργία αντικειμένου για τον αισθητήρα θερμοκρασίας, ο οποίος είναι
# συνδεδεμένος στον ακροδέκτη (pin) ADC4
tempSensor = ADC(4)

# Συνάρτηση μέτρησης της θερμοκρασίας. Η συνάρτηση επιστρέφει την θερμοκρασία σε
# βαθμούς Κελσίου
def readTemperature():
    # Λήψη της τιμής από τον ακροδέκτη ADC4 και μετατροπή της τιμής έτσι ώστε να ανταποκρίνεται στις προδιαγραφές του RPi Pico. Τα 3.3V αντιστοιχούν σε 65535 (2^16)
    reading = tempSensor.read_u16() * (3.3 / 65535.0)

    # Με τον τύπο που είδαμε πιο πάνω, γίνεται μετατροπή τιμής σε θερμοκρασία
    tempCelsius = 27 - (reading - 0.706) / 0.001721

    return tempCelsius

print("Internal Temperature:", readTemperature(), "°C")
```
